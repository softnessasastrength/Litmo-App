# Soft signal — public stub _muse

**_muse note:** Rewritten public stub. Mechanism kept; personal and
theological framing removed.

A soft signal is a stop. Plainly:

- Any participant can signal stop at any time.
- Stopping needs no reason, no justification, and no negotiation.
- When a stop is signalled, the session ends immediately.
- There is no social cost for stopping, and no requirement to explain
  afterwards in order to be believed or welcomed back.

The app's job is to make stopping easy, visible, and immediate — not to
ask why, and not to treat a stop as a failure.
