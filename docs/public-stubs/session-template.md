# Session template — public stub _muse

**_muse note:** Rewritten public stub. Session form only; personal
scripts from the original morning/spooning protocols are NOT copied here.

A public session, in form, is:

1. **Ask:** a named, bounded session is proposed, with what is welcome,
   what needs a fresh ask, and what is off limits stated in advance.
2. **Pause:** both participants confirm, explicitly and mutually, before
   the session starts. No confirmation, no session.
3. **Check in:** during the session, either participant can check in,
   narrow a boundary, or signal stop at any time.
4. **Close:** the session ends with a short check-in (see aftercare),
   and closing is always available without explanation.

A session template is a form, not a script. It does not prescribe what
two people say to each other beyond consent, boundaries, and closing.
