# Repair message template — public stub _muse

**_muse note:** Rewritten public stub. Template structure only; no
personal examples.

If a rupture happens, a repair message, if the other person is open to
receiving one, follows this structure, in plain words:

1. Name the rupture, briefly, without narrating the whole story.
2. Separate intent from impact: what was meant, and what was felt, are
   different things, and both can be stated.
3. Repair to be honest, not to be forgiven. There is no guarantee of
   reconciliation, and no requirement that the other person accept the
   repair.

A repair message is not a way to re-open a session, and it does not
override a stop, a block, or a report.
